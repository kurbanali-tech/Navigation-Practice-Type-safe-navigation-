# Type-Safe Navigation Practice

A collection of Jetpack Compose Type-Safe Navigation examples built while learning Android development and modern navigation patterns.

## Projects Included

### 1. Basic Type-Safe Navigation
- Navigation using type-safe routes
- Route definitions with sealed classes
- Navigation Compose integration

### 2. Type-Safe Navigation with Data Passing
- Passing arguments between screens
- Type-safe route handling
- Argument serialization

### 3. Type-Safe Navigation with Detail Screen
- Detail screen navigation
- Dynamic route parameters
- Safe argument retrieval

## Tech Stack

- Kotlin
- Jetpack Compose
- Navigation Compose
- Kotlin Serialization

## Concepts Covered

- Type-Safe Navigation
- Sealed Classes
- Route Management
- Data Passing Between Screens
- Navigation Arguments
- Detail Screen Navigation

## Purpose

This repository contains practice projects focused on mastering Type-Safe Navigation in Jetpack Compose before building larger real-world Android applications.
